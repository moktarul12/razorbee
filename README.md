# Razorbee website

Modern static site for Razorbee Online Solutions — software development, AI/ML, and products.

## Featured client
- [CapItCap](https://capitcap.com/) — boutique equity crowdfunding platform

## Stack
- Static HTML / CSS / JS
- Deployed on Netlify (`razorbee.com`)

## Local preview
Open `index.html` or:

```bash
npx serve .
```

## Deploy
```bash
netlify deploy --prod
```
